Etapa 3 · Mapa interactivo (JavaScript)

Mapa con la Maps JavaScript API y un marcador en mi ubicación. Requiere tu API Key en static/p4/api.json.

Falta tu API Key de Google Cloud. Abre static/p4/api.json y pega tu clave en apiKeyGoogle.

Cómo obtener tu API Key

  1. Entra a Google Cloud Console y crea/abre un proyecto.
  2. APIs y servicios → Biblioteca → habilita Maps JavaScript API.
  3. APIs y servicios → Credenciales → Crear credenciales → API Key.
  4. Restricciones de aplicación: HTTP referrers con tu dominio y http://localhost:*/*.
  5. Restricciones de API: únicamente Maps JavaScript API.

Pega la clave en static/p4/api.json → apiKeyGoogle.
